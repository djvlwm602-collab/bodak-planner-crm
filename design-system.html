§ 4.2.1 짝수 규칙 (사전 합의된 1px 정렬)

모든 폰트 크기는 짝수만 사용. 13px 만 단일 예외 (한국어 가독). 홀수 발견 시 가장 가까운 짝수로 흡수.

// ✅ 사용 가능 36 / 34 / 24 / 22 / 20 / 18 / 16 / 14 / 13 / 12 / 10 // ❌ 사용 금지 → ✅ 정렬 11 → 12 (Badge / 캘린더 요일 — Phase 4-C, 7건) 17 → 18 (CustomerHeader 제목 — Phase 4-C, 1건) 19 → 20 (PageHeader 제목 — Phase 4-C, 3건) inline 11 → 12 (HomeDashboard recharts axis — Phase 4-D, 7건)

v3 합성 스타일 표현 (size + native weight)

// Figma 스타일 ↔ 코드 표현 body3_medium ↔ "text-body3 font-medium" body3_bold ↔ "text-body3 font-semibold" body4_normal ↔ "text-body4" // 기본 weight 상속 h4 ↔ "text-h4 font-semibold" caption ↔ "text-caption"
cn() 의 tailwind-merge 확장으로 override 시 size만 교체되고 weight 보존됨 — Phase 4-B-pre. 예: cn('text-body5 font-medium', 'text-[11px]') → 'text-[11px] font-medium'
